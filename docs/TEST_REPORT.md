## 失败定位与修复

| 发现的问题 | 原因 | 修复与复测 |
|---|---|---|
| 第一轮多出店铺 | 大字商品包装、调料警告被当作店名，片尾回顾被当作章节 | 要求明确店铺切换证据，拒绝多条目回顾画面；加入真实误报回归 |
| 英文和驻京办名称误识别 | ASR 的同音/外语识别错误，如 Gitter Pan、Turpo Ba、Our Bucket、新疆租金罐 | 用同期字幕/门头 OCR 核对，保留原ASR与校正时间；不读人工标注来生成结果 |
| 短暂菜名遗漏 | 固定2秒采样跨过短字幕 | 在店铺转场与每句语音中点补充 OCR；拓展通用菜名抽取规则 |
| 错误地址 | 宽松匹配任何包含路/街/号的文字 | 改为明确地址上下文或道路加门牌，增加误报回归 |
| 模糊、重复门头截图 | 首次标题帧可能是运动转场，截图仅按类别去重 | 优选清晰稳定名称帧，场景避开介绍和相邻重复门头 |
| 旧缓存串视频风险 | 仅依据输出目录读取缓存 | 校验输入SHA256与完成状态；限制输入、输出及证据路径在项目内 |
| Python 3.11 渲染语法错误 | f-string 嵌套转义兼容问题 | 修复渲染表达式，渲染回归通过 |
