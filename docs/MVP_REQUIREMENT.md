# 第一版：探店攻略 · 验收基线

> 保留 2026-10-06 首版的目标与验收条件。当前项目范围、功能状态与下一步见 [PROJECT_BRIEF.md](../PROJECT_BRIEF.md)。

项目唯一构建目录：`E:\Workspace\video_agent`。

## 目标
将本地探店视频自动生成按店铺组织、有视觉证据和时间戳的中文图文笔记。

## 核心流程
本地视频 → 语音识别 + 中文画面 OCR → 店铺分段与实体校正 → 证据截图检索 → Markdown / HTML 笔记。

## 必须具备
- 自动处理真实视频，保留原始 ASR、OCR 与时间。
- 店铺名称、菜品、价格、地点和博主观点的证据提取。
- 店名优先结合同时段视觉文字校正，无法确认就标记待核对。
- 每家店保留清晰截图；支持时间戳定位。
- 本地运行，不要求 API 密钥；OCR/ASR 缓存可续跑。

## 暂缓
外部地址核实、路线规划、多平台抓取、商品订单识别、PPT 完整页提取、生成式综合推理。

## 验收
北京样例 BV1cHen6EEen 完成实际 ASR / OCR / 分段 / 笔记；图像可读，时间戳合法，所有引用文件存在。人工对照视频核验店铺分段和标题，不将标题声称的11家作为代码固定数量。报告事实提取的局限，机器运行通过不等于所有内容识别正确。
